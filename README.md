# 年代・性別アンケート

## 概要

性別と年代を選択するだけで回答できる、匿名アンケートアプリです。

PCやタブレットでの利用を想定しており、回答結果はCSVファイルに保存します。

## 主な機能

* 性別の選択（男性・女性）
* 年代の選択（10代・20代・30代・40代・50代・60代以上）
* 回答データのCSV保存
* 回答後、自動的に最初の画面へ戻る
* 回答者の氏名など、個人を特定する情報を収集しない

## 使用技術

* Java
* Spring Boot
* Maven
* HTML / CSS / JavaScript
* CSV

## 起動方法

### 必要な環境

* Java 21以上
* Windowsの場合はPowerShell

### 起動手順

1. 本リポジトリをクローンします。
2. プロジェクトのルートディレクトリへ移動します。
3. 次のコマンドを実行します。

```powershell
.\mvnw.cmd spring-boot:run
```

4. ブラウザで次のURLを開きます。

http://localhost:8080/

## 回答データ

回答データは、アプリケーションの作業ディレクトリに `responses.csv` として保存されます。

CSVファイルはExcelなどで開き、年代別・性別の集計に利用できます。


## 注意事項

* 本アプリはローカル環境での利用を想定しています。
